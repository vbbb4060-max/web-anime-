# 🎬 AnimeFlix - Netflix-Style Anime Streaming Platform

> **A fully functional, ad-free, multilingual anime streaming website**  
> Built with React, Node.js, Python scraper, and automatic subtitle translation.

---

## ✨ Features

- **Netflix-style UI** - Clean, responsive dark theme with smooth animations
- **Ad-Free Streaming** - All ads stripped from ZoroTV.bar sources
- **Multi-Language Subtitles** - Auto-translate subtitles to any language (LibreTranslate)
- **Full Anime Catalog** - Scrapes ZoroTV.bar for latest anime
- **Episode Management** - Organized episode lists with metadata
- **Search** - Find any anime instantly
- **Watch History** - Saves your recently watched episodes (localStorage)
- **Infinite Scroll** - Load more content as you browse
- **Video Proxy** - Bypass CORS and ad-blocking
- **Docker Ready** - One-click deployment with Docker Compose

---

## 🚀 Quick Start (5 Minutes)

### Prerequisites
- Docker & Docker Compose
- Python 3.8+
- Node.js 18+
- 2GB+ RAM

### One-Click Deployment

```bash
# Clone the repository
git clone https://github.com/yourusername/animeflix.git
cd animeflix

# Make the setup script executable
chmod +x setup.sh

# Run the setup script
./setup.sh
